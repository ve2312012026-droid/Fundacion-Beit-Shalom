# Fundación International Beit Shalom — El Remanente

Sitio web institucional de la Fundación International Beit Shalom, El Remanente.

Proyecto académico desarrollado para la asignatura de Programación Orientada a Objetos – Diseño Web Responsivo, Universidad Doctor Andrés Bello.

## Descripción

Este sitio web presenta la identidad, misión, visión, objetivos y programas de la Fundación International Beit Shalom. Está orientado a la formación integral de niños y niñas de comunidades vulnerables, promoviendo valores, educación, cultura y fe cristiana.

El diseño utiliza una paleta de colores en tonos azules y grises, buscando transmitir confianza, seriedad y cercanía.

## Páginas del sitio

- **index.html** — Página principal
- **nosotros.html** — Misión, Visión, Fines y Objetivos
- **programas.html** — Programas de formación
- **donar.html** — Información para patrocinadores y donaciones
- **contacto.html** — Datos de contacto y formulario

## Visualización local

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Instalar la extensión Live Server.
3. Abrir el archivo `index.html` con Live Server.

## Publicación

El sitio puede publicarse mediante GitHub Pages utilizando la rama `main` y la carpeta raíz del repositorio.
